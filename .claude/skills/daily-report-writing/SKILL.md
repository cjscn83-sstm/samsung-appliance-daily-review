# Daily Report Writing

## 목적

분석 데이터를 사람이 5분 안에 읽고 판단할 수 있는 일일 트렌드 리포트로 만든다.

## 절차

1. `artifacts/02-sentiment.md`와 카테고리 트리를 끝까지 읽는다.
2. 다음 산출물 형식대로 작성한다.
3. 분석 파일에 없는 주장·수치·인용은 절대 만들지 않는다.
4. 수집 0건인 품목도 섹션을 만들고 "어제 신규 후기 없음"으로 표시한다.
5. 광고성 비중이 50% 이상인 품목은 섹션 머리에 ⚠️ 경고 줄을 넣는다.

## 산출물 형식

```md
# 삼성 가전 일일 후기 리포트 — {어제 날짜}

## 한눈에 보기

- 총 수집 후기: N건
- 광고성 비중: X%
- 가장 긍정적인 품목: {품목명} (긍정 P / 부정 N)
- 가장 부정적인 품목: {품목명} (긍정 P / 부정 N)
- 종합 트렌드 한 줄: ...

## TV/영상∙음향

### TV

- 수집: N건 (긍정 P / 부정 Q / 혼합 R / 광고성 A)
- 핵심 키워드: 긍정 [디자인, AI, 화질], 부정 [번인 우려, 가격]
- 긍정 요약: 사용자들이 ... 라고 언급함.
- 부정 요약: ... 에 대한 불만이 반복됨.
- 대표 인용:
  - 긍정: "..." — [출처](URL)
  - 부정: "..." — [출처](URL)

### 모니터
...

## 주방가전

### 냉장고
...

## 리빙가전

### 세탁기/건조기
...

## 종합 트렌드

1. 카테고리 전반에서 두드러진 흐름 (3-4문장)
2. 주목할 신호 (예: 특정 시리즈 출시 직후 후기 급증)
3. 부정 의견이 누적되는 품목 경고

## 한계 및 주의

- 수집 출처: 네이버 블로그 + 일반 웹/카페/커뮤니티 (어제 게시물만)
- 광고성/체험단 포함 여부: 본 리포트는 광고성 후기를 매트릭스에는 포함했으나 인용 선정 시 정상 후기를 우선했음
- {카테고리}는 어제 수집 0건으로 추세 판단 불가

## 부록: 수집 메모

- 검색 도구 한계: ...
- 다음 회차 보강 필요 영역: ...
```

## 품질 기준

- 모든 수치는 `02-sentiment.md`에서 그대로 가져온다.
- 모든 인용에는 URL이 붙는다 (출처 누락 금지).
- "전반적으로", "대체로" 같은 모호한 표현 대신 수치를 쓴다.
- 종합 트렌드는 분석 데이터로 뒷받침되는 내용만.
- 카테고리 순서는 트리(TV/AV → 주방가전 → 리빙가전)를 따른다.

## 애매할 때

- 분석에 없는 인사이트를 추측하지 말고 "데이터 불충분"으로 표시.
- 광고성 비중이 높은 품목에서 인용을 뽑을 때는 광고성 표시가 없는 글을 우선.
- 한 카테고리 내에서 긍정/부정이 동률이면 그 사실을 그대로 표시 ("균형").
