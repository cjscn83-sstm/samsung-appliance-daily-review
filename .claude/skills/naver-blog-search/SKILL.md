# Naver Blog Search

## 목적

네이버 블로그에서 **지정 일자** D에 게시된 삼성 가전 후기를 빠짐없이 수집한다.

## 입력 인자

- `date` (필수): 수집 대상 일자, `YYYY-MM-DD` 형식. 오케스트레이터가 전달.
- 인자가 없으면 어제 날짜를 기본값으로 사용.

## 절차

1. `.claude/references/samsung-category-tree.md`를 읽어 세부 품목별 검색 키워드를 가져온다.
2. 각 키워드로 `mcp__naver-search__search_blog`를 `sort: "date"`(최신순), `display`를 크게(예: 20~30) 호출한다.
3. 검색 결과에서 **`postdate`(YYYYMMDD)가 입력 `date`와 일치하는 글만** 추린다. (네이버 API는 임의 과거일 필터가 없으므로 최신순 결과에서 해당 일자만 남기는 방식.)
4. 각 글에서 다음을 추출한다 (모두 검색 결과 필드에서 직접 취득 — WebFetch로 본문을 따로 받지 않는다):
   - 제목 (`title`, `<b>` 태그 제거)
   - URL (`link`)
   - 작성일 (`postdate`)
   - 작성자 (`bloggername` 그대로)
   - 본문 발췌: `description`(약 200자 스니펫)을 그대로 사용 (광고 문구가 섞이면 분리해 표시)
   - 광고성 의심 여부 (카테고리 트리의 식별 기준 적용)
5. URL이 중복되면 첫 번째만 유지한다.
6. 결과를 **`artifacts/{date}/01-naver-raw.md`**에 저장한다. 디렉터리가 없으면 만든다.

## 산출물 형식

```md
# 네이버 블로그 수집 결과 — {date}

## 수집 통계

- 총 수집: N건
- 광고성 의심: M건
- 카테고리 시도: 17개 세부 품목

## TV/영상∙음향

### TV (N건)

| 제목 | URL | 작성일 | 작성자 | 발췌 | 광고성 |
| --- | --- | --- | --- | --- | --- |
| ... | ... | ... | ... | ... | [정상] / [광고/체험단] / [광고 의심] |

### 모니터 (N건)
...

## 주방가전
...

## 리빙가전
...

## 수집 0건 품목

- {품목명}: 신규 후기 없음
- ...
```

## 품질 기준

- 입력 `date` 외 게시물은 절대 포함하지 않는다.
- URL은 `blog.naver.com` 도메인만 허용.
- 발췌는 원문에서 그대로 가져온다 (요약·재구성 금지).
- 광고성 표시는 카테고리 트리의 식별 기준을 그대로 적용한다.
- 모든 세부 품목에 대해 "수집 0건"이라도 행을 남겨 시도 사실을 보존한다.

## 애매할 때

- 작성일이 모호하면 해당 후기를 제외하고 사유를 메모.
- 같은 URL의 글이 여러 번 검색되면 첫 번째만 유지.
- 검색 도구가 없으면 작성자가 사용자에게 도구 연결을 요청.
